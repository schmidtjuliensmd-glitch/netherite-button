Netherite Button

Der Fichtenknopf wird bei dir als Netherite Ingot dargestellt. Eine erkannte Preiszeile im Tooltip kannst du lokal durch einen eigenen Text ersetzen.

Mod herunterladen ↓Vorschau ansehen
FabricClient-seitigJava 1.21.11
Funktionen

Direkt im Spiel einstellbar.

✓Menü-Taste selbst unter Optionen → Steuerung → Tastenbelegung festlegen.
✓Preistext ersetzen, Farbe auswählen, Vorschau anzeigen und speichern.
✓Änderungen gelten nur auf deinem Client. Der echte Serverpreis bleibt unverändert.
✓Dunkles, stabiles Ingame-Menü ohne den vorherigen Blur-Crash.

Installation

Schnell eingerichtet.

01

Fabric installieren

Fabric Loader für Minecraft 1.21.11 installieren und Fabric API in den Mods-Ordner legen.

02

JAR einfügen

Die heruntergeladene Mod-Datei ungeöffnet in .minecraft/mods legen.

03

Taste festlegen

Minecraft starten und unter Optionen → Steuerung → Tastenbelegung eine Taste für das Mod-Menü auswählen.

Der Mod verändert keine Serverdaten oder Serverpreise. Er ändert nur die Darstellung auf deinem eigenen Minecraft-Client.
