Installation

Quick setup.

01

Install Fabric

Install Fabric Loader for Minecraft 1.21.11 and place Fabric API in the mods folder.

02

Add JAR

Place the downloaded mod file unopened in the .minecraft/mods folder.

03

Start Minecraft

Start Minecraft with the Fabric profile and use the new visual change in-game.

The mod only changes the visuals on your own Minecraft client.
