# Netherite Button

Kostenloses Ressourcenpaket für **Minecraft Java Edition 1.21.11**.

- Fichtenknopf wird im Inventar und in der Hand als Netheritbarren dargestellt.
- Angezeigter Name: **Netherite Ingot**
- Platzierter Fichtenknopf und seine Funktion bleiben unverändert.
- Keine Mods erforderlich.

## Download

Nach Aktivierung von GitHub Pages steht der Download direkt über die Website bereit.

Inoffizielles Fanprojekt. Nicht mit Mojang Studios oder Microsoft verbunden.
