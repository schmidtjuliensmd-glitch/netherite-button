# Netherite Button Mod

Client-Mod für **Minecraft Java Edition 1.21.11 mit Fabric**.

## Funktionen

- Fichtenknopf erscheint im Inventar und in der Hand als **Netherite Ingot**.
- Eine Tooltip-Preiszeile wie `$ 18` kann lokal durch einen eigenen Text ersetzt werden.
- Einstellungen erfolgen über ein **Ingame-Menü**.
- Ersatztext, Farbe und Aktivierung sind einstellbar.
- Die Taste zum Öffnen des Menüs ist **nicht fest vorgegeben**. Sie wird in Minecraft unter **Optionen → Steuerung → Tastenbelegung** selbst festgelegt.
- Der Mod verändert keine Serverpreise. Er ändert nur die Darstellung auf dem eigenen Client.

## Installation

1. Fabric Loader für Minecraft 1.21.11 installieren.
2. Fabric API in `.minecraft/mods` legen.
3. `Netherite-Button-Mod-1.21.11.jar` ebenfalls in den Mods-Ordner legen.
4. Minecraft starten und die gewünschte Menü-Taste in den Tastenbelegungen festlegen.
