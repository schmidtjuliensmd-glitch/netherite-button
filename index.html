Der Fichtenknopf sieht bei dir wie ein Netherite Ingot aus. Zusätzlich kannst du eine Preiszeile wie $ 18 lokal durch deinen eigenen Text ersetzen – direkt über ein Menü im Spiel.

Netherite Ingot

Funktionen

Alles direkt im Spiel einstellbar.

Keine Befehle nötig. Die Taste zum Öffnen des Menüs legst du selbst in den normalen Minecraft-Steuerungseinstellungen fest.

Eigener Preistext

Ersetze eine erkannte Preiszeile wie „$ 18“ durch frei wählbaren Text, zum Beispiel „Custom“, „Mein Preis“ oder etwas Eigenes.

Ingame-Menü

Preisersatz an oder aus, Text ändern, Farbe auswählen, Vorschau ansehen und speichern.

Taste frei wählbar

Unter Optionen → Steuerung → Tastenbelegung bestimmst du selbst, welche Taste das Netherite-Button-Menü öffnet.

Nur deine Ansicht

Der echte Serverpreis wird nicht verändert. Der Mod ersetzt ausschließlich die Darstellung auf deinem Client.

Installation

In drei Schritten fertig.

01

Fabric vorbereiten

Installiere Fabric Loader für Minecraft 1.21.11 und lege die passende Fabric API in deinen Mods-Ordner.

02

Mod herunterladen

Lade die JAR über den Downloadknopf herunter und lege sie ungeöffnet in .minecraft/mods.

03

Taste festlegen

Starte Minecraft, öffne Optionen → Steuerung → Tastenbelegung und weise „Netherite Button Menü öffnen“ deine gewünschte Taste zu.

Der Mod ist client-seitig. Er verändert keine Preise, Daten oder Funktionen auf dem Server.
